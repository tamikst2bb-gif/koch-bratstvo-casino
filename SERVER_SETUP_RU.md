# Запуск казино на своём компьютере

## Что происходит при запуске

`start_bot.bat` запускает `start_bot.py`. Скрипт читает `BOT_TOKEN` из пользовательских переменных Windows, поднимает временный HTTPS-туннель и передаёт его адрес Python-боту. `main.py` обслуживает и страницу `index.html`, и API рейтинга, клубов и админ-панели на одном адресе. Данные хранятся в `leaderboard.db` рядом с файлами проекта.

## Запуск

1. Убедись, что команда `py --version` работает.
2. Убедись, что `ssh -V` работает (в Windows должен быть установлен OpenSSH Client).
3. Дважды щёлкни `start_bot.bat` и оставь открывшееся окно работать.
4. Кнопка меню «🎰 Играть» автоматически обновится на текущий адрес. Команда `/start` также отправит кнопку в чат.

При следующем запуске временный адрес может измениться; бот автоматически обновит кнопку меню. Остановка окна выключает бота и закрывает ссылку.

## Рейтинг и сохранность данных

База на этом компьютере отдельная от базы прежнего сервера. Она сохраняет только игроков, которые откроют это приложение и синхронизируются с этим компьютером. Без копии старой базы история игроков и их рейтинг не переносятся.

Скопируй `leaderboard.db` в безопасное место для резервной копии. Не добавляй эту базу и секреты в GitHub.

## Ограничения

Компьютер и окно запуска должны быть включены для работы бота и мини-приложения. Бесплатный туннель временный и может отключиться или сменить адрес; это вариант для проверки и личного использования, без гарантии круглосуточной доступности. Для постоянной работы понадобится сервер и постоянный HTTPS-домен.
