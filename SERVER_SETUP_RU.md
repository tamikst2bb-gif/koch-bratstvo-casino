# Как будет работать сервер

`main.py` запускает Telegram-бота и HTTP API в одном процессе. API отдаёт рейтинг, список клубов и остальные общие данные. Страница казино будет обращаться к нему по HTTPS.

## Подготовлено

- `requirements.txt` фиксирует используемую библиотеку Telegram Bot API.
- `render.yaml` описывает Python web service, проверку здоровья, переменные окружения и постоянный диск для `leaderboard.db`.
- `.gitignore` исключает токены, локальную базу данных и временные файлы из Git.

## Что понадобится для публикации

1. Репозиторий GitHub в аккаунте владельца проекта и аккаунт Render, подключённый к нему.
2. При создании Render Blueprint ввести токен бота в секрет `BOT_TOKEN` в панели Render. Не добавлять токен в файлы проекта.
3. После первого запуска скопировать выданный Render адрес сервиса и прописать его в пустые `LB` и `LB_API` в `index.html`; затем обновить опубликованную страницу.

`leaderboard.db` на компьютере не переносится автоматически. Она останется на месте; если в ней есть нужные игроки или клубы, базу потребуется отдельно перенести на постоянный диск сервера.

## Хранение и стоимость

В конфигурации выбран платный план Render Starter и диск 1 GB, чтобы SQLite переживала перезапуски и публикации. У Render бесплатные web services не поддерживают постоянный диск; стоимость диска сейчас указана как $0.25/GB в месяц, отдельно от тарифа сервиса. Перед созданием сервиса проверь актуальную сумму в Render.

Документация: [Render Blueprints](https://render.com/docs/blueprint-spec), [постоянные диски](https://render.com/docs/disks), [бесплатный тариф и его ограничения](https://render.com/docs/free).
